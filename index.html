手順4

通知をオンにする

全員

ここがいちばん大事です。　通知が届かないと、稽古日の変更やお支払いのご連絡に気づけません。トラブルの原因の大半がここです。

  1. Google Chatアプリで、右上のアイコン → 設定 を開きます。
  2. お仕事用アカウントを選び、通知 をタップしてオンにします。
  3. 次にスマホ本体の設定を開きます。 iPhone：設定 → 通知 → Google Chat
    Android：設定 → アプリ → Google Chat → 通知
  4. 「通知を許可」をオンにし、ロック画面にも表示されるようにします。
  5. 音とバイブレーションもオンにしておくと安心です。
うまくいかないときは
設定したのに通知が来ない（iPhone）
「通知の要約」に入れられている可能性があります。設定 → 通知 → 時刻指定要約 → アプリ一覧で、Google Chatがオフになっているか確認してください。オンだと決まった時間にまとめて届くので、急ぎの連絡に気づけません。
設定したのに通知が来ない（Android）
電池の節約機能でアプリが止められていることがあります。設定 → アプリ → Google Chat → バッテリー →「制限なし」または「最適化しない」を選んでください。
「集中モード」「おやすみモード」を使っている
そのモードの「通知を許可するアプリ」にGoogle Chatを追加しておいてください。
通知が多すぎて困る
オフにはせず、スペース（お部屋）ごとに調整してください。スペースを開いて名前をタップ → 通知 → 「メンションのみ」にすると、自分が名前を呼ばれたときだけ通知が来ます。ただし各公演（上演回）ごとのスペースは「すべて」のままにしておいてください。当日の急なご連絡が届かなくなります。「ミサキカク全体連絡」も「すべて」のままをおすすめします。

全員

メールアドレスをコピーする

  1. Gmailアプリを開き、右上のアイコンをタップします。
  2. 表示されたアカウント一覧の中から、お仕事用アカウントのメールアドレス部分を長押しします。
  3. 「コピー」が出てきたらタップします。 これでアドレスがスマホに一時的に記憶されます（打ち間違いを防ぐため、手入力はしないでください）。

  1. 上のボタンから登録フォームを開きます。
  2. 「メールアドレス」の欄をタップし、長押しして「貼り付け」を選びます。 キーボードは使わず、貼り付けだけで済ませてください。
  3. 活動名（本名でも芸名でも構いません）などの残りの項目を入力し、送信します。 お名前は姓と名の間にスペースを入れず、続けてご記入ください（例：三崎ひかり）。 3問目の「いまの状況」で「どこかで止まっている」を選んだ場合は、アドレスの入力は不要です。そのまま送信してください。

  5. Gmailアプリでお仕事用アカウントに切り替えてから、招待メールの 参加 ボタンを押します。
  6. Google Chatが開いて、スペースの一覧に表示されれば完了です。
フォームが開けない場合・アドレスがまだ作れていない場合 LINE（いま連絡を受け取っているミサキカク事業者用アカウント）か、メール info@misakikaku.com 宛に、活動名とアドレスを送っていただいても大丈夫です。

参加していただくスペース

Google Chatでは、グループのことを「スペース」と呼びます。用途ごとに分かれています。「ミサキカク全体連絡」以外は任意です。案内をお送りする関係でa〜eの招待も一律にお送りしますが、興味のないものは参加せずそのままにしていただいて構いません（自動的に何か送られてくることはありません）。すでに参加したあとでも、いつでも退出できます。

  • 必須ミサキカク全体連絡運営からの大事なお知らせ、表現者全員に関わる情報を流します。通知はオンが推奨です。流れる量の目安：月1回ほど（2026年1〜8月で7回）
  • 任意a_ミサキカクの募集ミサキカク主催の公演・イベントの出演募集。流れる量の目安：月1〜2回（2026年1〜8月で9回）
  • 任意b_他団体の募集ミサキカク以外の団体から届いた出演募集。流れる量の目安：2か月に1回ほど（2026年1〜8月で4回）
  • 任意c_スタッフ等（出演以外）の募集受付・撮影・制作など、出演以外のお仕事の募集。流れる量の目安：年に数回（2026年1〜8月で1回）
  • 任意d_無料の案内参加費のかからないワークショップ・勉強会などのご案内。流れる量の目安：月1回ほど（2026年1〜8月で8回）
  • 任意e_有料の案内費用のかかる講座・企画などのご案内。流れる量の目安：1〜2か月に1回（2026年1〜8月で6回）
  • 出演時各公演（上演回）ごとのスペース招待されたら参加し、通知はオンでお願いします。公演ごとに作成し、関係者をご招待します。連絡事項やディレクションの共有、当日の連絡もここで行います。

「ミサキカク全体連絡」とa〜eの6つは運営からのお知らせ専用で、書き込みはできません（各公演のスペースには書き込めます）。 ご連絡やお返事の方法は、各スペースの説明欄と、スペースの先頭に固定してあるご案内に書いてあります。

通知が要らないと思ったら a〜eの招待メールは、「参加」を押さなければそのままで構いません。すでに参加したものは、スペースを開いて名前をタップ → 通知 →「メンションのみ」にすると、自分が名前を呼ばれたときだけ届きます。それでも不要なら、同じ画面から退出もできます。a〜eの5つは、抜けても出演機会に影響しませんし、運営側から確認することもありません。あとから入り直すのも自由です。
